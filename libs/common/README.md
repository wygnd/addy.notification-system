# @addy/common

Shared-библиотека общих компонентов для сервиса уведомлений ADDY. Предоставляет переиспользуемые типы, константы, утилиты и конфигурации для всех микросервисов проекта.

## Установка

Библиотека является частью monorepo и устанавливается через `pnpm`:

```bash
pnpm install
```

## Использование

Импортируйте необходимые модули в любом сервисе проекта:

```typescript
import { NotificationResultEnum, Optional } from '@addy/common';
```

### Экспорт конфигураций

Библиотека экспортирует готовые конфигурации ESLint и Prettier для переиспользования в других пакетах:

```json
{
  "extends": ["@addy/common/eslint"]
}
```

## Экспорты

| Путь | Описание |
|---|---|
| `.` | Основные экспорты (enums, interfaces, constants, utils, types) |
| `./eslint` | Конфигурация ESLint |
| `./prettier` | Конфигурация Prettier |

### Модули

- **`enums`** — Перечисления: платформы, идентификации, уведомлений, VK, Telegram
- **`interfaces`** — Интерфейсы: ошибки, идентификация, уведомления, VK, Telegram
- **`constants`** — Константы: сообщения ошибок
- **`utils`** — Утилиты: нормализация ошибок, RPC-ошибки
- **`types`** — Типы: `Optional`, и другие вспомогательные типы

## Скрипты

| Команда | Описание |
|---|---|
| `pnpm build` | Сборка библиотеки через tsup |
| `pnpm dev` | Режим разработки с автопересборкой |
| `pnpm format` | Форматирование кода Prettier |

## Структура

```
libs/common/
├── src/
│   ├── constants/     # Константы
│   ├── enums/         # Перечисления
│   ├── interfaces/    # TypeScript-интерфейсы
│   ├── types/         # Вспомогательные типы
│   ├── utils/         # Утилиты
│   └── index.ts       # Точка входа
├── dist/              # Скомпилированный код
├── package.json
├── tsconfig.json
├── tsup.config.ts
├── eslint.config.mjs
└── prettier.config.mjs
```
