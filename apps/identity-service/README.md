# @addy/identity-service

Сервис управления идентификацией пользователей в системе уведомлений ADDY. Хранит и обрабатывает привязки пользователей к платформам (VK, Telegram).

## Функциональность

- **Управление идентификаторами** — создание и обновление привязок пользователей к платформам
- **Проверка существования** — запросы на наличие идентификатора по платформе
- **RabbitMQ-потребитель** — обработка команд от API Gateway
- **CQRS-паттерн** — разделение команд и запросов

## Технологии

| Компонент | Технология |
|---|---|
| Фреймворк | NestJS 11 |
| БД | PostgreSQL (Sequelize) |
| Кеш | Redis (ioredis) |
| Брокер | RabbitMQ (amqp-connection-manager) |
| Шифрование | bcrypt |

## Конфигурация

Переменные окружения наследуются из корневых настроек monorepo. Основные:

| Переменная | Описание |
|---|---|
| `PORT` | Порт HTTP-сервера |
| `RABBITMQ_URL` | URL RabbitMQ |
| `DB_HOST` | Хост PostgreSQL |
| `DB_PORT` | Порт PostgreSQL |
| `DB_USERNAME` | Логин PostgreSQL |
| `DB_PASSWORD` | Пароль PostgreSQL |
| `DB_NAME` | Имя базы данных |
| `REDIS_HOST` | Хост Redis |
| `REDIS_PORT` | Порт Redis |

## RabbitMQ

Сервис потребляет сообщения из очереди `notifications.identity`:

| Команда | Описание |
|---|---|
| `AddIdentityCommand` | Создать новую привязку пользователя |
| `UpdateIdentityCommand` | Обновить статус существующей привязки |

| Запрос | Описание |
|---|---|
| `ExistsIdentityQuery` | Проверить существование идентификатора |
| `ExistsPlatformQuery` | Проверить существование по платформе |

## Структура

```
src/
├── modules/
│   ├── database/        # Подключение к PostgreSQL
│   ├── identity/        # Основной модуль идентификации
│   │   ├── commands/    # Команды CQRS (Add, Update)
│   │   ├── queries/     # Запросы CQRS (Exists)
│   │   ├── controllers/ # RabbitMQ контроллер
│   │   ├── dtos/        # DTO
│   │   ├── interfaces/  # Интерфейсы сущностей и репозиториев
│   │   ├── mappers/     # Мапперы
│   │   ├── models/      # Sequelize-модели
│   │   ├── providers/   # Провайдеры
│   │   └── services/    # Бизнес-логика
│   ├── opt/             # Опциональные модули
│   └── redis/           # Подключение к Redis
└── shared/              # RPC-исключения
```
