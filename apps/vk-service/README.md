# @addy/vk-service

VK-бот для отправки уведомлений в рамках системы уведомлений ADDY. Взаимодействует с VK Bot API и отправляет сообщения пользователям через ВКонтакте.

## Функциональность

- **VK Bot API** — отправка сообщений через ВКонтакте
- **RabbitMQ-потребитель** — получение задач на отправку из API Gateway
- **Управление группами** — работа с VK-сообществами и чатами
- **Отправка сообщений** — рассылка уведомлений пользователям

## Технологии

| Компонент | Технология |
|---|---|
| Фреймворк | NestJS 11 |
| VK Bot API | node-vk-bot-api |
| Брокер | RabbitMQ (amqp-connection-manager) |

## Быстрый старт

```bash
# Установить зависимости
pnpm install

# Режим разработки
pnpm start:dev

# Сборка
pnpm build

# Продакшен
pnpm start:prod
```

## Конфигурация

| Переменная | Описание |
|---|---|
| `PORT` | Порт HTTP-сервера |
| `RABBITMQ_URL` | URL RabbitMQ |
| `RABBITMQ_QUEUE_NAME_VK` | Очередь VK |
| `VK_TOKEN` | Токен доступа VK-бота |

## RabbitMQ

Сервис потребляет сообщения из очереди `notifications.vk` и отправляет уведомления через VK Bot API. Ответы возвращаются в очередь результатов.

## Структура

```
src/
├── modules/
│   └── vk/              # Основной модуль VK
│       ├── controllers/ # Контроллеры
│       ├── interfaces/  # Интерфейсы VK API, методов и портов
│       ├── providers/   # Провайдеры
│       └── services/    # Сервисы VK API, групп и сообщений
└── shared/              # RPC-исключения
```
